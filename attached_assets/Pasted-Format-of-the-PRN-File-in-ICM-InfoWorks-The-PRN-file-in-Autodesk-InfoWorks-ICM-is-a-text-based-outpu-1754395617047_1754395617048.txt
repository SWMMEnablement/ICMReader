Format of the PRN File in ICM InfoWorks
The PRN file in Autodesk InfoWorks ICM is a text-based output file generated after a simulation, summarizing key results for nodes and links in the network. It is similar to the RPT file in SWMM5 but is limited to SI units (e.g., meters, cubic meters per second) without options for U.S. customary units like cubic feet per second (cfs). Here are the key details about its format and characteristics:
	•	Purpose: The PRN file provides a summary of maximum results for nodes (e.g., water levels) and links (e.g., flows, velocities) from a simulation, serving as a quick reference for model performance. It also includes mass balance information, such as total rainfall, runoff, inflow, outflow, and losses.
	•	Structure: The file is text-based and organized in a tabular or structured format, detailing simulation results. It includes sections for:
	◦	Node Data: Information like maximum water levels, depths, or flooding.
	◦	Link Data: Details such as flow rates, velocities, or volumes in conduits.
	◦	Mass Balance: Summary statistics (e.g., total rainfall, runoff, inflow, outflow, and losses) in SI units (e.g., cubic meters for volume, m³/s for flow).
	•	Limitations:
	◦	Outputs are exclusively in SI units, which can be a challenge for users needing U.S. customary units. Conversion to other units (e.g., cfs) requires post-processing in tools like Excel or Python using conversion factors (e.g., 1 m³/s = 35.3147 cfs).
	◦	Compared to SWMM5’s RPT file, the PRN file may lack detailed breakdowns (e.g., infiltration or dry weather flow components), requiring additional rows or processing for comprehensive comparisons.
	•	Accessing the PRN File: In InfoWorks ICM, you can view the PRN file by right-clicking the simulation object in the Explorer Window, selecting “Open As,” and choosing “PRN summary results (text)” from the Select Results dialog. The file opens in a Text File View if its size is less than 4MB; larger files may require external applications.
	•	Use Cases: The PRN file is often exported to tools like Excel or processed with scripts (e.g., Ruby or Python) for further analysis or unit conversion. Users can also use AI tools to automate unit conversions or enhance the file with additional data rows for better compatibility with other software like SWMM5.
For more details, refer to the Autodesk InfoWorks ICM documentation or resources like the SWMM5 blog for comparisons with other modeling tools.
